# Семейная Рисовалка

Семейная игра в рисунки и блеф (в стиле Drawful).

## Запуск

```
npm install
PORT=3000 npm start
```

## Ссылки

- Игроки: http://localhost:3000/
- Хост (телевизор): http://localhost:3000/host

## Заметки

- Состояние игры хранится только в памяти сервера и сбрасывается при перезапуске.
- Для отображения QR-кода на хост-странице положите файл `public/qr.png` (необязательно).
- 5–10 игроков, 3 раунда.
